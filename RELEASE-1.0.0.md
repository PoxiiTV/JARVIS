# J.A.R.V.I.S. v1.0.0

> *"Buenas tardes, señor. Todos los sistemas están operativos."*

Primera versión oficial. App de escritorio Windows: HUD 3D, voz, oído y acciones
donde toca (Hermes en el portátil Linux, Spotify/Tuya en este PC).

### Novedades

- **Aplicación de escritorio** — Electron, sin navegador, tutorial al primer arranque
- **HUD 3D** — esfera holográfica y «JARVIS» en el núcleo
- **Voz Fish Audio** — sin GPU; volumen por voz; reserva Álvaro
- **Wake «Yarvis»** — Vosk + Whisper (`large-v3-turbo`)
- **Cerebro Auto** — charla DeepSeek aquí; archivos/browser/terminal en Hermes
- **Personalidades** — JARVIS, Fermín, Kratos, Tobey, Amador, Saul, Sergio (independientes de la voz)
- **Spotify y Tuya** en este Windows
- **Memoria, briefing, visión, recibos de tools**

### Descarga

| Archivo | |
|---|---|
| **`JARVIS-Setup-1.0.0.exe`** | Instalador (recomendado) |
| **`JARVIS-Portable-1.0.0.exe`** | Sin instalar |

**Necesitas:** Windows 10/11 y [Python 3.10–3.12](https://www.python.org/downloads/) con *"Add Python to PATH"*.
No hace falta tarjeta gráfica.

La primera vez prepara el entorno (~200 MB, 1–3 min).

### Configuración

Dos claves **gratis**; el tutorial te guía:

- **Cerebro** — [openrouter.ai/keys](https://openrouter.ai/keys)
- **Voz** — [fish.audio/app/developers](https://fish.audio/app/developers)

Para **actuar** (HTML al escritorio, Chrome, terminal): Hermes en el Linux, misma `HERMES_KEY`.

Los `.exe` salen **sin claves**.
